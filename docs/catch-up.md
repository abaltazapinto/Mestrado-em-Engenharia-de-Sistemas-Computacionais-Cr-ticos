## Regra de prioridade

Recuperar por esta ordem:

1. trabalhos ou projetos já iniciados;
2. deadlines próximos;
3. conceitos que bloqueiam a compreensão das aulas atuais;
4. laboratórios;
5. teoria anterior não bloqueante.

Não recuperar simplesmente por:

Aula 1 → Aula 2 → Aula 3 → ...

## Critério de conclusão do catch-up

Considerar o catch-up concluído quando:

- [ ] todos os trabalhos ativos forem conhecidos;
- [ ] todos os deadlines próximos estiverem registados;
- [ ] os conceitos bloqueantes tiverem sido recuperados;
- [ ] for possível acompanhar as aulas atuais sem depender continuamente das anteriores;
- [ ] o estado das cinco UCs estiver atualizado neste documento.
